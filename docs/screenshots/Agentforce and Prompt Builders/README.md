# OTMP Agentforce & Prompt Builder

This folder contains screenshots of the **Agentforce Student Support Agent** and **Prompt Builder templates** implemented for the OTMP platform.

## Agentforce

* **Enrollment Support Agent** – Handles student enrollment-related queries.
* **Payment Support Agent** – Assists with payment and fee-related queries.
* **Trainer Support Agent** – Provides trainer-related information.
* **Batch Schedule Support Agent** – Handles batch schedule and timing queries.

## Prompt Builder

* **Enrollment Support Template** – Generates enrollment-related responses.
* **Payment Support Template** – Generates payment and fee-related responses.
* **Batch Support Template** – Generates batch schedule responses.
* **Trainer Support Template** – Generates trainer-related responses.
