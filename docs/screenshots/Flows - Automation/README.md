## OTMP  Salesforce Flows - Automation Screenshots

## Overview

The Online Training Management Platform (OTMP) uses Salesforce Flow Builder to automate business processes, update related records, send notifications, and retrieve Salesforce data for Agentforce AI actions.

The following flows are implemented in the OTMP project:

1. Payment → Enrollment Automation
2. Enrollment → Batch Strength Update
3. Enrollment Confirmation Email
4. Get Batch Details
5. Get Enrollment Details
6. Get Payment Status
7. Get Trainer Details
