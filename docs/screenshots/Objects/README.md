# Salesforce Objects - Fields and Relationships

This folder contains screenshots documenting the Salesforce data model used in the Online Training Management Platform (OTMP).

## Objects

The main OTMP objects include:

- Student
- Course
- Trainer
- Batch
- Enrollment
- Payment
- Meeting

## Fields

Screenshots show the important fields configured for each object, including:

- Text and Email fields
- Number and Currency fields
- Date fields
- Picklists
- Lookup/Master-Detail relationships
- Status and business-related fields
