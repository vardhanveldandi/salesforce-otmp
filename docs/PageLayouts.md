# Salesforce Page Layouts

## Overview

Page Layouts define how OTMP Salesforce records are displayed and organized for users.

## Student Page Layout

The Student Page Layout organizes student information such as personal details, contact information, and student status.


## Enrollment Page Layout

The Enrollment Page Layout organizes enrollment information including course, batch, enrollment status, and payment status.


## Payment Page Layout

The Payment Page Layout organizes payment information such as payment amount, payment status, and payment date.

## Business Benefit

- Provides a consistent user interface.
- Makes important fields easy to access.
- Improves data entry efficiency.
- Helps users manage OTMP records effectively.
