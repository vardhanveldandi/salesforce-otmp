# Contributing

Thank you for your interest in the Salesforce OTMP project.

## How to Contribute

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Update the relevant documentation.
5. Verify that screenshots and diagrams are clear.
6. Submit a pull request.

## Documentation Guidelines

- Use clear Markdown.
- Keep file names descriptive.
- Place screenshots in the appropriate folder.
- Place diagrams in the diagrams folder.
- Update documentation when Salesforce configuration changes.

## Pull Requests

Please clearly describe:
- What was changed
- Why it was changed
- Any Salesforce configuration affected
