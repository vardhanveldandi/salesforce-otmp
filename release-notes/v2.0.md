# OTMP Version 2.0 — Customer Service & Experience

## Overview

Version 2.0 extends OTMP with customer-facing Experience Cloud
features and Service Cloud case-management capabilities.

## Features Implemented

### Experience Cloud
- Created Experience Cloud site
- Configured OTMP Home Page
- Configured Courses Page
- Configured Experience Cloud navigation

### Case Management
- Enabled Case Management
- Configured Case Record Types
- Configured Case Statuses
- Configured Case Assignment Rules

### Queues
Created support queues for:

- Enrollment Support
- Payment Support
- Trainer Support
- Technical Support
- Certificate Support

### Omni-Channel
- Configured Service Channel
- Configured Routing Configuration
- Configured Presence Configuration
- Configured Presence Statuses
- Configured Omni-Channel utility
- Configured Case routing
- Configured Case ownership assignment

## Developer Edition Limitation

The Omni-Channel configuration was implemented and tested
to the extent supported by the Salesforce Developer Edition.

AgentWork/work-item creation could not be fully validated in
the Developer Edition environment.
