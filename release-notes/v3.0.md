# OTMP Version 3.0 — Agentforce AI

## Overview

Version 3.0 introduces AI-powered student support capabilities
using Agentforce, Prompt Builder, Flows and AI actions.

## Agentforce

### OTMP Student Support Agent

Created an Agentforce-based Student Support Agent.

### Subagents

Configured specialized support capabilities for:

- Payment Support
- Enrollment Support
- Batch Schedule Support
- Trainer Support

## AI Actions

Configured actions using Salesforce Flows for retrieving:

- Enrollment Details
- Payment Details
- Batch Details
- Trainer Details

## Prompt Builder

Created prompt templates for:

- Student Welcome Email
- Batch Performance Summary
- Payment Fee Reminder

## AI Data

AI-related information can be tracked using:

- AI Interaction records
- Student information
- Enrollment information
- Payment information
- Batch information
- Trainer information

## Automation Integration

Agentforce AI capabilities are integrated with Salesforce
Flows to retrieve relevant OTMP information.

Implemented and Tested
